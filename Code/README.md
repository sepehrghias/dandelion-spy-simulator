# Dandelion Spy Simulator · Source code

See the [project README](../README.md) for installation, architecture, experiments, results, and report generation.

If your terminal is already in this directory:

```bash
python -m pip install -r requirements.txt
python main.py --help
python main.py demo --seed 1 --p 0.5 --packets 30
```

Experiment outputs are written to the project root's `results/` and `figures/` directories.
